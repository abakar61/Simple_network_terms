# What is a Server?

A **server** is a **computer, hardware device, or software application** that **provides services, data, resources, or applications to client devices** over a network. Servers are essential in both **home** and **business (corporate)** networks.

Unlike a client, which requests services, a **server listens for requests, processes them, and sends back responses**.

Common examples of servers include:

- Web servers
- File servers
- Database servers
- Mail servers
- Print servers
- DNS servers
- DHCP servers
- Cloud servers

---

# How a Server Works

A server is always waiting for requests from clients. When a client sends a request, the server:

1. Receives the request.
2. Processes the request.
3. Retrieves or creates the required data.
4. Sends the response back to the client.

A server can handle many requests at the same time, allowing multiple users to access services simultaneously.

---

# Server-Client Communication

Servers and clients communicate using the **request-response model**.

The communication process is:

1. The client sends a request.
2. The server receives the request.
3. The server processes the request.
4. The server sends a response.
5. The client receives and uses the data.

---

# Communication Protocols

Servers and clients communicate using network protocols. The most common protocol suite is **TCP/IP (Transmission Control Protocol/Internet Protocol)**.

TCP/IP is responsible for:

- Establishing communication between devices.
- Transferring data reliably.
- Detecting lost packets.
- Retransmitting missing packets.
- Ensuring data arrives in the correct order.

Other common protocols include:

- HTTP / HTTPS
- FTP
- SMTP
- DNS
- DHCP
- SSH

---

# Where Servers Can Be Located

Organizations can host servers in different locations depending on their needs.

Servers may be located:

- On-premises (inside the organization)
- In a private data center
- In a public cloud
- In a hybrid cloud environment

# Components of a Server

A server contains specialized hardware designed to operate continuously and handle large workloads.

## Central Processing Unit (CPU)

The CPU is the brain of the server. It processes instructions, performs calculations, and handles client requests.

## Graphics Processing Unit (GPU)

Some servers include GPUs for tasks such as artificial intelligence, machine learning, graphics rendering, and scientific computing.

## Memory (RAM)

RAM temporarily stores data while the server processes requests. More RAM allows the server to support more users and applications at the same time.

## Storage

Storage permanently stores operating systems, applications, databases, user files, and backups.

Common storage devices include:

- SSD (Solid State Drive)
- HDD (Hard Disk Drive)
- NVMe SSD
- Cloud Storage

## Motherboard

The motherboard connects all server components and allows them to communicate with each other.

## Network Interface Card (NIC)

A NIC connects the server to a network so it can communicate with clients, other servers, and the Internet.

## Power Supply

Servers require reliable power supplies. Enterprise servers often include multiple power supplies for redundancy and continuous operation.

# Types of Servers

## File Server

A file server stores, manages, and shares files such as documents, images, videos, PDFs, and spreadsheets across a network.

## Database Server

A database server stores and manages databases. It processes database queries and ensures data is stored securely and efficiently.

Examples include:

- Microsoft SQL Server
- MySQL
- PostgreSQL
- Oracle Database

## Print Server

A print server receives print requests from users and sends them to the appropriate network printer.

## Application Server

An application server hosts software applications that users access over a network without installing them on every computer.

## Web Server

A web server hosts websites and web applications. It receives requests from web browsers and returns webpages to users.

Examples include:

- Apache
- Nginx
- Microsoft IIS

## Mail Server

A mail server manages email services by sending, receiving, storing, and delivering email messages.

## DNS Server

A DNS (Domain Name System) server converts domain names, such as **www.google.com**, into IP addresses that computers use to communicate.

## DHCP Server

A DHCP (Dynamic Host Configuration Protocol) server automatically assigns network settings such as IP addresses, subnet masks, default gateways, and DNS server addresses to devices.

## Proxy Server

A proxy server acts as an intermediary between clients and the Internet. It improves security, hides client IP addresses, filters traffic, and caches frequently accessed content.

## FTP Server

An FTP (File Transfer Protocol) server allows users to upload and download files over a network.

## Virtual Server

A virtual server is created using virtualization software called a hypervisor. Multiple virtual servers can run on a single physical server.

## Cloud Server

A cloud server is a virtual server hosted by a cloud provider. It offers scalability, remote access, high availability, and flexible pricing.

Examples include:

- Amazon Web Services (AWS)
- Microsoft Azure
- Google Cloud

## AI Server

An AI server is designed for artificial intelligence and machine learning workloads. It uses powerful GPUs or specialized processors to train and run AI models.

## Security Server

A security server protects networks and systems by providing services such as firewalls, authentication, intrusion detection, intrusion prevention, and access control.

# Real-World Example

When you open **Google Chrome** and visit **www.google.com**:

1. Google Chrome (the client) sends a request to Google's web server.
2. The web server receives the request.
3. The server processes the request.
4. The server retrieves the requested webpage.
5. The server sends the webpage back to the client.
6. Google Chrome displays the webpage on your screen.

# How to Choose the Right Server

When selecting a server, organizations should consider:

- Performance requirements
- Number of users
- Storage capacity
- Processing power
- Scalability
- Budget
- Maintenance requirements
- Physical, virtual, or cloud deployment

---

# Key Points

- A **server provides** services, data, resources, or applications to clients.
- A **client requests**, while a **server responds**.
- Servers use the **request-response model** for communication.
- Communication usually occurs using **TCP/IP**.
- Servers contain specialized hardware such as **CPU, GPU, RAM, storage, motherboard, NIC, and power supplies**.
- Servers can be **physical, virtual, cloud-based, or AI-optimized**.
- Common server types include **web, file, database, application, mail, DNS, DHCP, FTP, proxy, print, AI, and security servers**.
- Servers can process many client requests simultaneously and are designed to operate continuously.

# Network Bandwidth 🌐📡

## Overview

**Network bandwidth** is the maximum amount of data that a network can transfer in a specific period of time.

It represents the **capacity of a network connection** and determines how much data can be transmitted at once.

Bandwidth is usually measured in:

- **Bits per second (bps)**
- **Megabits per second (Mbps)**
- **Gigabits per second (Gbps)**

Example:

```
100 Mbps = Network can transfer up to 100 megabits of data per second
```

---

# Bandwidth vs Throughput ⚖️

Although bandwidth and throughput are related, they are not the same.

## Network Bandwidth

Bandwidth is the **maximum possible data transfer capacity** of a network.

Example:

```
Internet connection = 100 Mbps bandwidth
```

It means the connection can theoretically transfer up to 100 Mbps.

---

## Network Throughput

Throughput is the **actual amount of data successfully transferred** through the network.

Example:

```
Bandwidth: 100 Mbps
Actual throughput: 85 Mbps
```

Throughput is usually lower than bandwidth because of:

- Network congestion
- Packet loss
- Network protocols
- Router and switch limitations
- Signal interference

---

# Bandwidth vs Speed 🚀

Bandwidth and speed are often confused, but they are different.

## Bandwidth

Bandwidth refers to:

> The amount of data a network can carry.

Example:

```
Bandwidth = 500 Mbps
```

---

## Speed

Network speed refers to:

> The actual rate at which data travels through the network.

Speed depends on:

- Network protocols
- Device capability
- Wired or wireless connection
- Server performance
- Network conditions

Example:

A device using an **802.11b Wi-Fi adapter** cannot receive more than:

```
11 Mbps
```

even if the network supports higher speeds.

---

# Network Bandwidth Hog 🐷

A **bandwidth hog** is a device, application, or user consuming an excessive amount of network bandwidth.

This can slow down the entire network.

## Examples of bandwidth hog activities:

- High-quality video streaming
- Large file downloads/uploads
- Cloud backups
- Online gaming
- Unauthorized usage
- Malware or DDoS attacks

---

# Effects of Bandwidth Hogs

Bandwidth hogs can cause:

- Slow internet access
- High latency
- Poor application performance
- Reduced employee productivity
- Network congestion

Example:

```
Many users
     |
     ↓
High bandwidth usage
     |
     ↓
Network slowdown
```

# Monitoring Network Bandwidth 📊

Network administrators use bandwidth monitoring tools to understand network usage.

A good monitoring solution should help administrators:

## Traffic Analysis

- Monitor network traffic in real time
- Analyze bandwidth usage
- Identify heavy users and applications

## Troubleshooting

- Detect network bottlenecks
- Find bandwidth-consuming devices
- Identify performance problems

## Network Management

- Apply Quality of Service (QoS)
- Prioritize important applications
- Limit unnecessary traffic

---

# Network Bandwidth Planning 📈

Network administrators must plan bandwidth according to:

- Number of users
- Applications being used
- Business requirements
- Future growth
- Peak traffic periods

Poor planning can cause:

### Too little bandwidth

```
Low capacity
     ↓
Congestion
     ↓
Slow network
```

### Too much bandwidth

```
Unused capacity
     ↓
Higher cost
```

The goal is to find the right balance between:

```
Performance + Cost
```

# Increasing Network Bandwidth 🔼

There are two main ways to improve bandwidth:

## 1. Purchase More Bandwidth

Organizations can increase their Internet capacity by upgrading their ISP plan.

Example:

```
100 Mbps → 1 Gbps
```

---

## 2. Optimize Existing Bandwidth

Administrators can improve performance by:

### Traffic Management

Using:

- Traffic shaping
- Traffic policing
- Load balancing

### Network Design

Improving:

- Subnet design
- Router placement
- Switch configuration

### Access Control

Creating policies to:

- Block unnecessary websites
- Limit non-business traffic
- Control application usage

### Scheduling

Moving heavy tasks to non-peak hours:

- Software updates
- Backups
- Large file transfers

# Key Differences Summary

| Feature | Bandwidth | Throughput | Speed |
|---|---|---|---|
| Meaning | Maximum capacity | Actual successful transfer | Data transfer rate |
| Measurement | Mbps/Gbps | Mbps/Gbps | Mbps/Gbps |
| Affected by | Network capacity | Congestion, errors, devices | Device and network conditions |
| Example | 1 Gbps connection | 800 Mbps actual transfer | 600 Mbps Wi-Fi speed |
